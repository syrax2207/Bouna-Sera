# MASTER PROJECT DIRECTIVE — BUONA SERA

Act as a senior creative director, product designer, interaction designer and senior React engineer.

Build a bespoke, premium, responsive website concept for Buona Sera Cafe in Sector 104, Noida.

## Creative direction
Contemporary Italian Editorial Dining: warm, elegant, photographic, human, sophisticated and distinctive.

Proposed palette:
- Background `#F5F0E7`
- Surface `#EAE2D4`
- Text `#262820`
- Olive `#596449`
- Terracotta `#B66B4E`
- Muted gold `#B69A68`

Proposed typography:
- Cormorant Garamond for display.
- DM Sans for body/UI.
- DM Mono for small labels.

These are concept choices, not verified existing brand assets. Adapt if owner-provided branding becomes available.

## Experience
Build these sections:
1. Navigation
2. Cinematic hero
3. Brand introduction
4. Signature experiences
5. Interactive menu
6. Story/atmosphere
7. Asymmetric gallery
8. Genuine reviews (only if verified)
9. Visit/contact
10. Footer

## Motion
Use Motion for React where appropriate:
- Staggered hero typography.
- Subtle image reveal.
- Header transition.
- Scroll-triggered section entrances.
- Menu transitions.
- Gallery lightbox.
- Modal transitions.
- Mobile drawer.
- Refined hover/tap feedback.

Use CSS for simple transitions. Respect reduced motion. Avoid scroll hijacking, excessive parallax, autoplay audio and animations that delay access to content.

## Technical
Use the existing project framework and build configuration. Proposed stack is React, Vite, Tailwind CSS, Motion for React and Lucide React, subject to inspection. Keep data separate from components. Do not add a backend without a real requirement.

## Content integrity
Never invent address, contact details, opening hours, menu items, prices, ingredients, dietary labels, reviews, awards, facilities, business history or services. Mark unknown data internally as needing confirmation. Use owner-provided/licensed photos or clearly tracked placeholders. Do not represent the prototype as the official business website.

## Quality
All visible controls must work. Build responsive desktop/tablet/mobile compositions. Use semantic HTML, accessible labels, visible focus, keyboard navigation, optimized images and SEO metadata based on verified facts.

## Execution
Follow the eight-batch roadmap. Work on one batch at a time. Inspect current files before edits. Preserve working functionality. Do not regenerate the whole app for local changes. Run relevant checks after each batch and report changed files, tests, known issues and acceptance status.
