# BATCH 3 — NAVIGATION & CINEMATIC HERO

Implement desktop navigation, accessible mobile navigation and the hero.

Hero content should include an eyebrow (if useful), strong headline, concise support copy, primary menu CTA, secondary directions CTA only if a verified destination exists, and a high-quality real/licensed image.

Motion: restrained staggered headline reveal, image scale reveal, CTA entrance, header background transition on scroll. Ensure text contrast and quick access to content. Respect reduced motion.

Mobile drawer must support keyboard interaction, Escape to close, focus handling and closing after anchor selection.

Do not invent business claims. Use approved copy or clearly marked draft copy. Test desktop/tablet/mobile and report.
