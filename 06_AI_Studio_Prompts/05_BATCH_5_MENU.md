# BATCH 5 — INTERACTIVE MENU

Build a reusable, data-driven menu using a separate data file.

Implement:
- Category selection.
- Search by dish name.
- Optional dietary filter only when verified.
- Dish image, name, description and confirmed price.
- Dish detail dialog.
- Empty state and clear/reset action.
- Responsive category controls.
- Accessible labels and focus management.

Category names and dishes must match the current owner-approved menu. Do not invent ingredients, prices, availability or allergen information. Do not add a fake cart or checkout.

Ensure filters combine correctly, modal works with keyboard and touch, and menu content is not duplicated across components.
