## Project guardrails

- This is a concept demonstration, not an official Buona Sera Cafe website.
- Do not imply that the café has hired VEYRO or approved the design.
- Do not invent menu items, prices, opening hours, contact details, offers, testimonials, awards, facilities or business policies.
- Treat all researched business details as provisional until checked against a current owner-approved source.
- Use clearly labelled placeholders where information is missing.
- Do not publish or deploy the concept under a misleading official domain or identity.
- No application code should be generated until the documentation and asset/content decisions are reviewed.
